# Changelog

All notable public beta changes to Makoto Glass will be documented here.

The project is currently in early beta. Version numbers and protocol details may change while testing continues.

## Unreleased

- Public beta repository created.
- Added installation and standalone iPhone pairing documentation.
- Added MAKOTO LAB Limited Beta License.
- Added public issue templates for bug reports and feature requests.

## 0.1.0-beta

Initial public beta release planned.

Expected highlights:

- Custom launcher for Google Glass Enterprise Edition 2
- Apple Notification Center Service (ANCS) integration
- Apple Media Service (AMS) integration
- Notification display and history
- Incoming-call notification handling
- Media controls and Now Playing information
- Camera and photo viewer
- Tilt Wake and automatic brightness
- Bluetooth reconnect and recovery
- Foundation for system-wide Accessibility-based control

Makoto Link for iPhone is not included in this release and will be documented separately when TestFlight distribution becomes available.
